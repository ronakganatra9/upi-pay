# Contributing

Thanks for contributing to UPI Pay.

## Development

This project is intentionally simple and backend-free.

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Test the app on desktop and an Android device when the change affects camera or UPI intent behavior.
5. Run `node --check app.js` before opening a pull request.
6. Open a pull request with a concise description and screenshots for UI changes.

## Scope

Prefer vanilla HTML, CSS, and JavaScript. Avoid introducing a framework or backend unless the change has a clear requirement and is discussed first.
